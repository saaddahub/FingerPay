# FingerPay brand

The logo is **the Ridge Coin** (v2, 2026-11-20): a coin struck with a fingerprint's arch ridges. Full rules, geometry and sizes are in `docs/design/SYSTEM.md` §7. Open `preview.html` in a browser to see every file on paper and ink.

| File | Use |
|---|---|
| `fingerpay-mark.svg` | The mark, 40 px and up |
| `fingerpay-mark-small.svg` | 20–40 px |
| `favicon.svg` | 16–20 px (solid coin, no ring) |
| `fingerpay-app-icon.svg` | App icon, PWA, social image |
| `fingerpay-wordmark.svg` | "FingerPay", Inter Display Medium as outlines |
| `fingerpay-lockup.svg` | Coin + wordmark, horizontal |
| `fingerpay-lockup-stacked.svg` | Coin above wordmark |

All files use `currentColor` (except the favicon and app icon, which carry their own ink tile). Ink `#0A0A0B` on paper, `#F5F5F7` on ink. No accent colour, ever.

The v1 logo (traced from a PNG, SF Pro wordmark that couldn't be licensed for the web) is kept in `archive/v1/` for history.
